ro_description Package
This package contains the hardware abstraction and simulation configurations for the ROSMaster X3.


Contents
urdf/: Xacro-based kinematic definitions for the base, mecanum wheels, and sensor suites (LiDAR, IMU, RGBD).  
meshes/: High-fidelity STL files used for visualization and collision modeling in Gazebo.  
launch/: Contains sim.launch.py for launching the robot into a simulated environment.
